# PowerBI-SuperStore-Analysis
The **SuperStore Sales Dashboard** is an interactive **Power BI** project that analyzes retail sales, profit, customer segments, and regional performance through dynamic visualizations. Using **DAX, data modeling, and interactive filters**, the dashboard delivers actionable insights to support data-driven decisions and improve business performance.


## Dataset

The dataset used for this project is available below:

- SuperStore Sales DataSet.xlsx (download to view)
- Sum of Sales.csv (viewable directly on GitHub)
